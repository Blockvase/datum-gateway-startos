# Datum Gateway on StartOS

[DATUM Gateway](https://github.com/Blockvase/datum_gateway) is Blockvase's fork of the CONVOY DATUM Gateway. It lets ASIC miners build their own block templates against a local Bitcoin node, mining solo or through a DATUM-supporting pool. This package wires it to your node, publishes the stratum endpoint for your miners, and asks the node to notify it on every new block.

- **Upstream repo:** <https://github.com/Blockvase/datum_gateway>
- **Wrapper repo:** <https://github.com/Blockvase/datum-gateway-startos>
